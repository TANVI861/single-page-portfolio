# Single Page Portfolio Website

A responsive single-page portfolio website developed using HTML, CSS, and JavaScript.

## 🚀 Features

- Responsive single-page design
- Home section with animated typing effect
- About Me section
- Skills section
- Education section
- Projects section
- Internships section
- Contact section
- GitHub and LinkedIn links
- Smooth navigation

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
